# ADR-002: ルーティングポリシーに OPA (Rego) を使う

- **日付**: 2026-06-22
- **状態**: Accepted

## 決定

ルーティングルールを OPA の Rego で定義し、`go-opa` ライブラリで評価する。

## 理由

- if/else の Go コードより宣言的で読みやすく、非エンジニアでもルールを理解・変更しやすい
- ポリシーをホットリロードできるため、サービス再起動なしにルールを変更できる
- 将来的に Webhook Validation や Audit Log と同じポリシーエンジンを共有できる

## トレードオフ

- Rego の学習コストがある（最初は YAML → Go の単純マッチングで代替し、後で移行する）
